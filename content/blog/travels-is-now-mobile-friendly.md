Had some recent trips and so while updating the website with new photos I thought it would be a great time to also add a mobile friendly way to look at it too!

<!-- more -->

For this, I dived into it using Claude and after some back and forth on the current mobile site a plan was made to edit it in such a way that would be mobile friendly and aesthetically pleasing.

Claude seems to excel at web tasks and I had full confidence that this was going to be a simple task for it to achieve. It's the kind of thing I would have spent a few evenings tinkering with and having to look up some obscure CSS for.

In the process, it also sped up the build script for the website by a factor of 4x-5x caching a lot of data that doesn't need to be rebuilt and reducing multiple calls to subprocesses. 

Couple more travels in the works this year but in the meantime check out the latest over at [travels.carlocarfora.co.uk](https://travels.carlocarfora.co.uk)!
